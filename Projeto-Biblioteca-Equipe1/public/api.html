Como usar esta API

Todas as rotas respondem em application/json; charset=utf-8 a partir da URL base http://localhost:8080. Nas rotas POST e PUT, envie um objeto JSON no corpo da requisição.

Status HTTP Significado Quando acontece nesta API
200 OKSucessoListagem, busca por ID, resumo ou atualização concluída.
201 CreatedCriadoNovo autor ou novo livro cadastrado com sucesso.
204 No ContentRemovidoExclusão concluída (resposta sem corpo JSON).
400 Bad RequestRequisição inválidaJSON malformado no corpo ou :id não numérico (ex.: /api/livros/abc).
404 Not FoundNão encontradoID não existe no banco ou rota /api/... inexistente.
409 ConflictConflito / RegraNome de autor duplicado, ISBN repetido ou tentativa de excluir autor com livros.
422 UnprocessableDados inválidosCampo obrigatório vazio, faixa numérica inválida (ano_publicacao) ou autor_id inexistente.
